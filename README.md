# Document Management System

## 📌 Overview

The **Document Management System (DMS)** is a web-based application designed to store, organize, manage, and retrieve digital documents efficiently. It helps users maintain important documents securely while reducing manual paperwork and improving accessibility.

This system provides a centralized platform for uploading, categorizing, viewing, updating, and deleting documents.

---

## 🚀 Features

* User authentication (Login/Register)
* Upload and manage documents
* Categorize documents for easy access
* Search functionality for quick retrieval
* Update document details
* Delete unwanted documents
* Secure storage management
* User-friendly dashboard

---

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python Flask
* **Database:** SQLite / MySQL
* **Version Control:** Git & GitHub

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/hawkeyemihawk07/Document-Management-System.git
```

### 2. Navigate to project directory

```bash
cd Document-Management-System
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in browser

```bash
http://127.0.0.1:5000/
```
